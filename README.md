## Working agreement

Use personal folders for individual exploration. Link to notebooks and results from weekly notes rather than copying them. Move useful joint work into `shared/` when the team agrees.

Before each meeting, everyone adds a short update to their own file in that week's folder. One rotating meeting owner updates the root agenda and weekly meeting notes. This keeps overlapping edits uncommon.

Exploratory work is welcome: document what you tried, what happened, and what you would try next, including unsuccessful approaches.
