You are reviewing reference labels, not parser output. One table record can contain many cells: approve only after checking every displayed row, header, value and unit. Approvals are shared across categories. Correction flags stay unverified until corrected and reviewed again.

How saving and category counts work

Table review covers 11 table records; number review covers those same 11 tables plus 5 visual cards (16 records). Text/organization covers 43 records, including those 5 cards. The categories overlap, so these are not 70 separate labels: there are 54 unique records.

Decisions autosave in this browser when browser storage is available. A local webpage cannot silently update the benchmark files. Use Export decisions to save a portable JSON file, then tell Codex where you saved it and ask to import it. Importing updates the benchmark and regenerates reviewed-only scores and the three reports. The reports continue to show their saved counts until then. Restore an export to continue in another browser with the same label version.

No files are uploaded and no model calls are made. Pending notes are included in exports. If browser storage is unavailable, export before closing this tab.
