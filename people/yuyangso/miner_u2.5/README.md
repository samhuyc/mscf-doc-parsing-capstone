# MinerU 2.5 – PubTabNet Benchmark

## Setup and run

Use Python 3.11 and run the following commands from the repository directory:

```bash
pip install -r requirements.txt
mineru-models-download
python minerU2.5.py
```

When prompted to download models, select Hugging Face and the pipeline backend.

For CPU-only execution on macOS or Linux:

```bash
MINERU_DEVICE_MODE=cpu python minerU2.5.py
```

The PubTabNet dataset is streamed automatically from Hugging Face. Benchmark outputs are generated by the script.
